# Carina Farias Order House

Queria pra mim um novo site pros segmentos seguintes: tem uma churrascaria, o meu colega vende pra mais de 40 churrasco por dia, porém eu quero ter uma probabilidade de venda de 130 churrasco por dia. Então criei pra mim uma landing page. De acordo com as categorias pra adicionar os elementos que ele tem pra vender, tanto suco, refrigerante, água, entre outras coisas que se vende dentro de uma churrascaria. Modalidade de entrega e de impressão pra sair as notas após sair o pedido. Deixa uma bazinha pra próxima atualização pra integração dos pagamentos dele, tanto PIX como cartão de crédito, débito, entre outros, e as bandeiras disponíveis.

E o nome da churrascaria dele é Churrascaria do Michel. Bota uma landing page bem profissional, bem atraente, estilo full porn, com as fotos do churrasco. Que ele não precisa bater foto de pratos novos, mas bota um full porn bem bonito aí. E atraente. Já dá água na boca dos clientes.
